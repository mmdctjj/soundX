## mobile 包被 HyperOS 静默禁用 → 通过 adb 启用恢复

- 设备：Xiaomi goku（24072PX77C，红米 K70 Pro），Android 16 / SDK 36，USB 已连。
- 现象：点击 app 图标立刻消失/强退，看起来像被卸载。
- 真因：`dumpsys package com.audiodock.app` 显示 `installed=true` 但 `enabled=0`，说明包还在，只是被 PackageManager 禁用了——这是 MIUI「USB 安装管理」开关关闭时 `adb install` 安装 debug 包的典型表现。
- 修复：
  1. `adb shell pm enable com.audiodock.app` → 状态从 `enabled=0` 变 `enabled=1`。
  2. `adb shell monkey -p com.audiodock.app -c android.intent.category.LAUNCHER 1` 拉起。
  3. `dumpsys activity activities` 确认 `topResumedActivity=com.audiodock.app/.MainActivity`，稳定在前台。
- 根治（下次仍会复发）：进手机「设置 → 开发者选项 → USB 安装（USB 安装管理）」打开，并用弹窗里的「USB 调试安全设置」一并同意。也可在「设置 → 应用 → 管理应用 → 右上角三个点 → 显示所有应用 → 找到 com.audiodock.app → 启用」临时救回。

## test 分支流水线默认推 MinIO + Harbor（去掉静默跳过逻辑）

### 修改文件
- `.github/workflows/feat-test-release.yml`：去掉 desktop + android 两个 MinIO upload step 上的 `if: ${{ env.MINIO_ENDPOINT != '' }}` 条件
- `.github/workflows/docker-publish-test.yml`：保留 Harbor login step 无条件执行（仅加注释说明 secrets 配置位置）

### 根因
- **MinIO**：原 `if: ${{ env.MINIO_ENDPOINT != '' }}` 在 `secrets.MINIO_ENDPOINT` 没设时整个 step **静默跳过**——push 到 feat/test 后用户看不到任何上传动作，pipeline log 也没明显错误。
- **Harbor**：原 Harbor login step 是无条件执行的，看似会推 Harbor；但如果 `secrets.HARBOR_*` 没设，docker/login-action 失败会 **fail 整个 job**，导致 build-and-push step 不跑——用户观察到的是「Harbor 没新镜像」，但根因其实是 Harbor login 把整个 job 拖垮，连 GHCR/Docker Hub 也没出镜像。

### 修改思路
- MinIO：去掉 `if` 后 step 总是尝试推送；凭据缺失时 `aws s3 cp` 失败 → step fail → job fail（明显错误，比静默跳过更容易发现）。
- Harbor：**故意保留无条件 login**——secrets 缺失时 step fail 立即报错，比"Harbor 跳过但 GHCR/Docker Hub 也跟着挂"更好定位。原本想加 `if + continue-on-error: true` 让 Harbor secrets 缺失时不影响其他 registry，但 build-and-push step 用 `tags: ${{ steps.meta.outputs.tags }}` 一次推所有 registry，Harbor tag 推送失败会让整个 build-and-push fail，反而浪费一次 multi-platform build——所以回退到无条件 login + 注释提醒。

### 用户需要在 GitHub 仓库 Settings → Secrets and variables → Actions 配置
- **MinIO**：`MINIO_ENDPOINT` / `MINIO_BUCKET` / `MINIO_ACCESS` / `MINIO_SECRET` / `MINIO_REGION`（可选，默认 us-east-1）
- **Harbor**：`HARBOR_REGISTRY` / `HARBOR_USERNAME` / `HARBOR_PASSWORD`

### 验证
- 两个 YAML 文件用 `python3 -c 'yaml.safe_load(...)'` 验证语法合法。
- 推送 feat/test 后，如果 secrets 已配，会看到 MinIO step 输出 installers 列表、Harbor login 成功 + build-and-push 推送到 GHCR/Docker Hub/Harbor 三个 registry；如果缺失则立即在对应 step 报错。
